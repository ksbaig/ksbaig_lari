# Lari vehicle marketplace

A responsive React and Vite marketplace for browsing cars, bikes, trucks, and vans in Pakistan.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Deploy

The `main` branch deploys automatically to GitHub Pages using GitHub Actions:

<https://ksbaig.github.io/ksbaig_lari/>

To enable deployment, open the repository's **Settings → Pages** and select **GitHub Actions** as the build and deployment source. The workflow publishes the Vite production build after each push to `main`.
